# 우리 반 AI 키우기 (가칭)

특수교육 프로젝트 수업 「분리배출 AI 도우미」를 위한 이미지 학습 도구다.

티쳐블 머신과 같은 원리로 브라우저 안에서 이미지 분류 AI를 학습시키지만, 지적장애·중도중복장애 학생이 쓸 수 있도록 ‘반려 AI 키우기’ 게임으로 만든다. 학생들은 작은 로봇에게 사진 먹이를 주고, 공부시키고, 퀴즈로 확인하고, 헷갈려하면 골고루 먹여 고쳐 준다. 다 자란 로봇은 분리수거함 옆에서 학교 구성원을 안내한다.

- 계정·서버 없이 기기 안에서만 동작하고, 학생 사진은 밖으로 나가지 않는다.
- 학생 수준(가·나·다)에 따라 표시 방식과 참여 방법(버튼, 스위치, 소리 신호)이 달라진다.
